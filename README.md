# CheckerChecks 🎬📸

> Intelligent gear inventory, production gig checklists, client rental tracking, and cloud sync for creative professionals.

## Features

- 📦 **Inventory Management**: Track all cameras, lenses, lighting, and gear with serial numbers and availability status.
- 📋 **Gig Packing Checklists**: Smart pack/unpack validation with warning tags for missing or rented-out equipment.
- 🤝 **Rental Management**: Track active client rentals, expected returns, and auto-sync gear availability.
- ☁️ **Cloud Sync (Firebase)**: Local-first offline capability with automatic background sync to Cloud Firestore.
